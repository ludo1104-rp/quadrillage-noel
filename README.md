# Se repérer sur un quadrillage – Spécial Noël

Un jeu de plateau pour lire et donner des coordonnées et suivre ou écrire un programme de déplacement, seul sur iPad ou en 2 équipes au TVI. Version de Noël : la hotte du Père Noël donne le nombre de cases, les défis rapportent des sucres d'orge.

Ouvrir l'application : https://ludo1104-rp.github.io/quadrillage-noel/
